GeorgeTech Folder Manager

CLIENT INSTALLATION
===================

1. Close classic Outlook.
2. Run Install-GeorgeTech-Folder-Manager.cmd.
3. Windows may warn that a command script was downloaded.
4. Confirm only when the file came directly from GeorgeTech.
5. The script verifies the exact certificate thumbprint before trusting it.
6. The script downloads and launches the current ClickOnce setup.exe.
