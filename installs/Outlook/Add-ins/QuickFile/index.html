Install

  1. Download and extract the ZIP file.
  2. Close classic Outlook.
  3. Run Install-GeorgeTech-Folder-Manager.cmd.
  4. Open classic Outlook when installation finishes.
Windows may show a security warning because the installer adds the GeorgeTech publisher certificate for the current Windows user. Continue only when the download came directly from georgetech.uk.

Requirements

  • Windows 10 or Windows 11
  • Classic Outlook for Windows
  • Internet access during installation
  • Not compatible with the new Outlook
